# Voice Assistant Application

This is a Python-based voice assistant application that can perform various tasks such as opening websites, applications, getting weather updates, searching Wikipedia, and more. It uses speech recognition, text-to-speech, machine learning, and integration with various Python libraries to enhance functionality.

## Features

- **Voice Commands**: Listen for specific commands to open applications, search the web, control the system, and more.
- **Weather Updates**: Get the current weather information for a given city.
- **Wikipedia Search**: Search for articles on Wikipedia and read out the summaries.
- **Keyboard Automation**: Perform keyboard operations like typing, pressing keys, and executing hotkeys.
- **MongoDB Integration**: Commands and intents are stored in MongoDB for dynamic updating and training.
- **GUI Interface**: A simple GUI to interact with the assistant.
